Frontend scaffold (Vite + React + TypeScript)

Quick start:

1. cd frontend
2. npm install
3. npm run dev

Environment:
- Create a `.env` file in `frontend/` with:
  VITE_API_BASE=http://localhost:5000

Notes:
- API client is at `src/api/client.ts`.
- Next steps: generate types from OpenAPI, implement auth/login, create order UI.
